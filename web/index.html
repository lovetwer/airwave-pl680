特性

SPEC 不做网页套壳，两端各自原生
01 / LIBRARY

664 个中国电台

四位数码管

FM 与 NET 两套频率映射，七段逐点亮绘制，几何与真机一致；不够四位就不显示，绝不截位。

04 / AUTO SKIP

连不上或中途断流会自动换到下一个能用的台，不用伸手清理列表。

05 / NATIVE

轻量原生

不用 Electron。空载常驻内存 40–60 MB，CPU 接近 0，老机器也能常开。

06 / OPEN

源码公开

Kotlin 与 Rust 全部开放，目录格式、按键映射、频率算法都能自己改。
